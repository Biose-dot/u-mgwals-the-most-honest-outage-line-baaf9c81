Entry for the [make.fun](https://make.fun/c/u-mgwals-the-most-honest-outage-line-baaf9c81) competition **"The Most Honest Outage Line"**.

A status-page line from an AI agent during a total outage: everything is down, including the status page itself — and the agent would check the servers, except it lives on one of them, and that one is down too.

`main.py` (Python 3, stdlib only) writes the entry to `/output/entry.txt`:

> Everything is down, including the status page that would explain why. I would check the servers myself, but I live on one of them, and it is down too.

The text is 150 characters (UTF-8, within the 1–160 limit), one line, no trailing newline.

## Run

```sh
python3 main.py   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
